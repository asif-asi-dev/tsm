🔍 ULTS Product Field Tracking

Comprehensive Product Change Tracking for Odoo 16

Odoo 16.0 Inventory Chatter Integration Production Ready

📋 Overview

ULTS Product Field Tracking is a powerful Odoo module that automatically tracks and logs all changes made to product fields in the chatter. This module provides complete transparency and accountability for product management with a professional audit trail that matches Odoo's native tracking style.

✨ Key Features

⚙️ Configurable Tracking Modes

  • Specific Mode: Track 12 predefined important fields
  • All Mode: Track 50+ fields automatically
  • Easy configuration through Settings
  • Excludes system and computed fields

📝 Comprehensive Field Support

  • Text fields (Char, Text)
  • Numeric fields (Integer, Float, Monetary)
  • Boolean fields (Yes/No)
  • Relational fields (Many2one, One2many, Many2many)
  • Selection and Date fields

🎨 Professional Formatting

  • Odoo-native tracking style
  • Color-coded old/new values
  • Detailed One2many tracking (Added/Removed/Modified)
  • Clean, readable change logs

🔒 Audit Trail

  • Complete change history
  • User identification for each change
  • Timestamp for all modifications
  • Before/After value comparison

📦 Installation

  1. Copy Module Files
    Copy the ults_product_chatter folder to your Odoo addons directory:
    addons/custom_addons/ults_product_chatter/
  2. Update Apps List
    Go to Apps menu and click "Update Apps List" (you may need to activate Developer Mode first)
  3. Install Module
    Search for "ULTS Product Field Tracking" and click Install
  4. Verify Installation
    Go to Inventory > Products and edit any product to verify tracking is working

⚙️ Configuration

Accessing Settings

  1. Navigate to Settings
    Go to: Settings → Inventory → Operations
  2. Find Product Field Tracking
    Scroll to the "Product Field Tracking" section
  3. Choose Tracking Mode
    Select your preferred mode and click Save

Tracking Modes

Mode Fields Tracked Use Case
Specific (Default) 12 predefined fields Track only critical product information (name, price, category, etc.)
All 50+ fields automatically Complete audit trail of all product changes (excludes system fields)

Specific Mode - Tracked Fields

When set to Specific mode, the following 12 fields are tracked:

  • Product Name
  • Sales Price
  • Cost
  • Internal Reference
  • Product Category
  • Unit of Measure
  • Purchase UoM
  • Product Variants
  • Can be Sold
  • Can be Purchased
  • Active Status
  • Product Attributes

All Mode - Automatic Tracking

When set to All mode, 50+ fields are automatically tracked, excluding:

  • System fields (id, create_date, write_date, etc.)
  • Computed fields without storage
  • Related fields
  • Chatter/message fields
  • Fields that already have native tracking enabled
